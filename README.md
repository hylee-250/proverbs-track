# 잠언 필사 챌린지

팀원들이 잠언 31장을 필사하면서 각자의 진도를 체크하고 팀 현황을 함께 보는 웹앱입니다.
FastAPI로 만들었고, Cloudtype에 배포하고 Neon(PostgreSQL)을 DB로 씁니다. 휴대폰에서 쓰기 편하도록 화면 크기에 맞춰 바뀌는 반응형으로 만들었습니다.

## 주요 기능

- **로그인 없이 이름만 선택**: 환경 변수 `MEMBERS`에 넣은 이름이 첫 화면에 나타나고, 한 번 고르면 그 기기에서 계속 기억합니다.
- **내 진도**
  - 31장을 칸으로 보여주며, 누르면 완료되고 다시 누르면 확인 후 취소됩니다.
  - 진도율(%)과 `N / 31장`, 완료한 절 수를 보여줍니다.
  - 오늘까지 권장 진도와 비교해 앞서는지 뒤처지는지, 남은 기간 하루에 몇 장씩 써야 하는지 알려줍니다.
  - 다음에 쓸 장과 그 장의 주제, 연속 필사 일수(현재와 최고 기록)를 보여줍니다.
  - 필사 달력에 기간 중 날짜별 완료 장 수를 진하기로 표시합니다.
  - 배지 8종을 줍니다(첫 걸음, 25/50/75%, 3일/7일 연속, 8장, 완주). 완주하면 축하 효과가 나옵니다.
- **팀 현황**
  - 팀 평균 진도율, 완주 인원, 계획대로 진행 중인 인원, 오늘 필사한 장 수를 보여줍니다.
  - 멤버별 진도를 진도순, 최근순, 이름순으로 정렬해 볼 수 있고, 이름을 누르면 그 멤버의 상세 진도를 읽기 전용으로 봅니다.
  - 장별 완료 인원을 히트맵으로, 최근 활동을 피드로 보여줍니다.
- **나눔**: 장마다 묵상과 마음에 남은 구절을 남기고 공유합니다. 장별로 모아 보거나 내 글만 볼 수 있고, 내 글은 삭제할 수 있습니다.
- **전체 표**
  - 모든 멤버 × 31장 진도표를 보여주고, 칸을 눌러 대신 체크하거나 취소할 수 있습니다.
  - CSV로 내려받을 수 있습니다(엑셀에서 한글이 깨지지 않습니다).
  - 명단에서 빠진 이름의 기록이 있으면 알려줍니다.
- **기타**: 다크 모드, 홈 화면에 추가(PWA)를 지원하고, 모든 날짜와 시간은 **서울 시간(Asia/Seoul)** 기준입니다.

### 진도율 계산 방식

잠언은 장마다 길이가 다르기 때문에(18절에서 36절까지, 총 915절), 진도율은 **완료한 장의 절 수 합 ÷ 915**로 계산합니다.
그래서 실제로 쓴 분량에 가깝습니다. `N / 31장` 표시는 장 수 그대로 보여줍니다.

> 성경 본문은 저작권이 있으므로 앱에는 장 번호, 절 수, 장별 주제만 들어 있습니다. 필사는 각자 성경책으로 합니다.

## 환경 변수

| 이름 | 설명 | 예시 |
|---|---|---|
| `MEMBERS` | 팀원 이름. 쉼표로 구분합니다 | `홍길동,김철수,이영희` |
| `DATABASE_URL` | Neon 연결 문자열. 없으면 로컬 `local.db`(SQLite)를 씁니다 | `postgresql://...neon.tech/neondb?sslmode=require` |
| `START_DATE` | 시작일 (기본값 `2026-10-01`) | `2026-10-01` |
| `END_DATE` | 종료일 (기본값 `2026-11-30`) | `2026-11-30` |
| `APP_TITLE` | 화면 제목 (기본값 `잠언 필사 챌린지`) | `OO교회 잠언 필사` |

진도 기록은 DB에 **이름 기준**으로 저장됩니다. 그래서 `MEMBERS`에 사람을 추가하거나 빼도 기존 기록은 남아 있습니다. 다만 이름을 바꾸면 다른 사람으로 인식하니, 이름을 바꿀 때는 주의하세요.

## 로컬 실행

```bash
pip install -r requirements.txt
cp .env.example .env   # MEMBERS를 입력하고, DATABASE_URL은 지우면 SQLite로 실행됩니다
uvicorn app.main:app --reload --port 8731
```

브라우저에서 http://localhost:8731 을 엽니다. 테이블은 앱이 시작될 때 자동으로 만들어집니다.

## 배포 (Neon + Cloudtype)

1. **Neon**
   1. [neon.tech](https://neon.tech)에서 프로젝트를 만듭니다. 리전은 Asia Pacific(Singapore)를 추천합니다.
   2. Dashboard → Connect에서 **Pooled connection** 문자열을 복사합니다. `postgresql://...-pooler...?sslmode=require` 형태입니다.
2. **Cloudtype**
   1. 새 프로젝트를 만들고 이 GitHub 저장소를 연결한 뒤, 프리셋으로 **Python**을 고릅니다.
   2. Python 버전은 3.12, Port는 `8000`으로 둡니다.
   3. Start command는 `uvicorn app.main:app --host 0.0.0.0 --port 8000` 입니다.
   4. 환경 변수에 `MEMBERS`, `DATABASE_URL`(필요하면 `START_DATE`, `END_DATE`, `APP_TITLE`도)를 입력합니다.
   5. 배포가 끝나면 `https://<도메인>/healthz`가 `{"ok": true}`를 돌려주는지 확인합니다.
3. 접속 주소를 팀원들에게 공유합니다. 휴대폰 브라우저의 "홈 화면에 추가"를 쓰면 앱처럼 쓸 수 있습니다.

멤버를 추가하거나 빼려면 Cloudtype 환경 변수 `MEMBERS`를 고친 뒤 재시작하면 됩니다.

## 구조

```
app/
  main.py        라우트 (내 진도, 팀, 나눔, 전체 표, CSV)
  services.py    진도율·페이스·연속일·배지·달력 계산 (서울 시간 기준)
  models.py      chapter_progress, chapter_note, activity_log 테이블
  config.py      환경 변수 로딩
  proverbs.py    잠언 장별 절 수와 주제
  templates/     Jinja2 + HTMX 화면
  static/        CSS, JS, PWA 파일
```
